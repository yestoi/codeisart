# The S2 format in the driver, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the steady sender (`show/display/colorlight_sender.py`, its packets in `colorlight_packets.py`) puts on the wire what the spike sender put there when the wall was clean on 2026-09-30: `tools/sender_spike/send.py --s2 --fps 60.32 --sync-level <level> --byte36 05`. That removes the second picture (a copy of bright rows a few rows away) that our 112-byte sync at 59 frames a second makes the card draw.

**Architecture:** the packet builders change bytes, the sender changes what it sends a tick, and nothing else moves. The sync becomes the S2 sender card's: 1036 bytes, EtherType `01 00` (packet type 0x01, source type 0x00), a frame counter at byte 14, bytes 16 to 18 `ff ff ff`, byte 26 `01`, the declared rate `01 3c` at bytes 31 and 32, the level byte at 35 and at 38 to 40, byte 36 `05` (the switch that makes the card obey the level). One sync a frame, the rows right behind it, no 0x0A brightness packet at all, the row header's tail `00 00` instead of `08 88`, `OUTPUT_FPS` 60.32. The `Sender` keeps one sync as a `bytearray` per level and writes the counter into it before each send. The prime (the first burst after a start or a pause: rows, no sync, so the first sync shows a whole frame), the hold, the pause after a failed send, the restart, the parent-death drain and the close are untouched; `CLOSE_FRAMES` follows the rate (60). The tests pin every byte to the spike's own builders, which are what went on the wire at the wall.

**Tech Stack:** Python 3.11+, numpy, pytest. The spike sender `tools/sender_spike/send.py` is imported by the tests as the reference (it stays as it is).

**Spec:** `docs/superpowers/reviews/2026-09-30-ghosting/00-path-forward.md` sections 2 and 4 (the format and the wall checks), `07-wall-session.md` (the runs; finding 7 for byte 36, "the winning configuration" for the packet list). The steady sender's own design: `docs/superpowers/specs/2026-09-29-route-a-steady-sender-design.md` (the parts about the rate and the packets are superseded by this plan; the hold, restart and close are not).

- The sync's bytes are the spike's `sync_packet(replace(S2_SYNC, level=b, byte36=0x05, counter_start=0), n)` for frame n, byte for byte; the rows are the spike's `row_packets(rows, tail=b"\x00\x00")`. A test compares each with the spike's builder; no byte is typed into the driver from memory.

## Review Focus

Inputs the spec implies that no task's tests would otherwise exercise; each has its test in the task that owns the code:

1. The frame counter wraps: byte 14 goes 0 to 255 and back to 0 (every 4.2 s at 60.32), never 256 (Task 2).

```python
- 0x01 the sync ("display frame"), 1036 bytes, EtherType 0x0100 (source type 0x00): a frame counter at 14,

- 0x55 a row, EtherType 0x5500 | row >> 8: row & 0xFF, pixel offset (2 bytes), pixel count (2 bytes), then
```

```python
def _row_header(row: int, offset: int, count: int) -> bytes:
    return _eth(ETH_ROW | (row >> 8)) + bytes([row & 0xFF, offset >> 8, offset & 0xFF,
                                               count >> 8, count & 0xFF]) + ROW_TAIL
```

`sync_bytes` and `frame_packet`:

```python
def sync_bytes(b: int, counter: int = 0) -> bytes:
    """The S2's sync with the level byte b and the frame counter (kept to a byte)."""
    payload = bytearray(FRAME_PAYLOAD_LEN)
    payload[COUNTER_OFFSET - 14] = counter & 0xFF
    payload[16 - 14 : 19 - 14] = b"\xff\xff\xff"
    payload[26 - 14] = 0x01
    payload[31 - 14 : 33 - 14] = b"\x01\x3c"                # the declared rate: 60 Hz
    payload[LEVEL_OFFSET - 14] = b
    payload[36 - 14] = 0x05                                 # the brightness switch: the level is obeyed
    payload[38 - 14] = payload[39 - 14] = payload[40 - 14] = b
    return _eth(ETH_FRAME) + bytes(payload)
```

```python
def frame_packet(brightness: float, counter: int = 0) -> bytes:
    return sync_bytes(level_byte(brightness), counter)
```

```python
def bursts(packets):
    """The packets cut at each burst's start: a sync, or a row 0 right after a row (a prime, which has no sync)."""
    out, cur = [], []
    for p in packets:
        row0 = p[12] == ROW and p[13] == 0 and p[14] == 0 and p[15:17] == b"\x00\x00"    # row 0, its first chunk
        starts = p[12] == SYNC or (row0 and cur and cur[-1][12] == ROW)
        if starts and cur:
            out.append(cur)
            cur = []
        cur.append(p)
    if cur:
        out.append(cur)
    return out
```
