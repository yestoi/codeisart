## Decisions
- No software limiter (`BrightnessLimiter` is `ArcadeConfig`'s): renderer, governor, push. `gamma` 1.0 to 2.2 (B2).
- A governor the config refuses: the module's defaults govern the static error frame, so the wall is neither dark
  nor ungoverned; dark only if that fails too. A bad show.toml: `Config()` and the error on that frame.
- A render raise aborts to attract (spec 4.6). A push failure does not abort: the amendment's lights rule (10 s, all
  off, relight) is how spec 4.6 applies to push; the next step re-sends the last governed frame (a torn push).
- The banner stays every 40 source lines (`test_banner_returns_every_40_source_lines`). No `NEXT` on an empty queue.
  Cursor blink 1 Hz. If the iteration runs long, T-deploy's `deploy/` files move to it13.
