# Roadmap — wall arcade, and the show daemon (from iteration 10)
**End goal:** A camera-and-microphone arcade for the four-panel LED wall (four 64x32 panels mounted 2 x 2, 128x64) that a stranger at a festival is playing within ten seconds of walking up, unprompted: the attract director shows a mirror of them, a wordless hand-up pictogram invites them, a game starts at once, the three-door menu is opt-in, and the session ends when they leave. Every game is verifiable headlessly on the Mac from scripted and recorded inputs, producing contact sheets, GIFs and feel metrics an agent can judge, with no game code that knows which machine it runs on. 128x64 is the design layout and the only one games are built and judged for (owner decisions Q32 and Q33, 2026-09-28; until then the goal named 128x32 as the design layout and 64x64 as first-class, for two panels); the engine takes its size from config and every game still runs at a size it does not declare, so a bring-up on fewer panels shows a picture. The arcade runs on its own Raspberry Pi 5 driving the spare Colorlight 5A-75E with the raw Colorlight backend, leaving the show Pi 4 untouched. The game list is the one the owner accepted from the review: Copy Me as the hero, Pong, Quick Draw, Dodge, Tug, Flap, Swat, Paint, Strongman and Freeze, with life, beat and the puppet mirror in the attract catalog.

Source documents: the arcade spec as amended by spec revision 3, the core plan with its amendments, and docs/superpowers/reviews/2026-09-26-arcade-adversarial-review.md (sections 6, 7, 10a).
